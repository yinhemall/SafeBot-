GUARDIAN • DISCORD SECURITY

Security for your Discord server.

Guardian is a security-focused Discord bot built to protect, moderate and monitor your server with simple commands and automatic protection.

FEATURES

What Guardian does.

01 / SECURITY

Anti-Spam

Detects rapid message activity and can automatically timeout users who repeatedly spam.

02 / SECURITY

Anti-Link

Detect unwanted external links and Discord invites and remove them automatically.

03 / MODERATION

Moderation

Ban, kick, timeout, warn and clear messages directly through Discord slash commands.

04 / LOGGING

Security Logs

Record important moderation and security events inside a dedicated Discord log channel.

05 / LOCKDOWN

Server Lockdown

Quickly lock a channel or activate security lockdown when your server needs immediate protection.

06 / WARNINGS

Warning System

Keep track of user warnings and manage moderation actions directly from Discord.

COMMANDS

Built around Discord.

/help View all available Guardian commands.
/security View the current security configuration.
/ban Ban a member from the server.
/kick Remove a member from the server.
/timeout Temporarily restrict a member.
/warn Give and track moderation warnings.
/clear Remove messages from a channel.
/lock Lock a channel for security purposes.
